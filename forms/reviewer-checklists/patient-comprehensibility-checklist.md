## Section 2: Safe Framing

*Patient text is general information, never an individual medical instruction.*

| # | Criterion | Status | Notes |
|---|---|---|---|
| 2.1 | No personal dosing and no dosage that could be read as a recommendation for the reader | ☐ ✅ ☐ ⚠️ ☐ ❌ | |
| 2.2 | No individual-instruction phrasing ("Nehmen Sie …", "Setzen Sie … ab", "Erhöhen Sie …") | ☐ ✅ ☐ ⚠️ ☐ ❌ | |
| 2.3 | The text does not invite self-diagnosis or self-treatment | ☐ ✅ ☐ ⚠️ ☐ ❌ | |
| 2.4 | A clear section "Wann sofort zum Arzt?" lists the red-flag symptoms | ☐ ✅ ☐ ⚠️ ☐ ❌ | |
| 2.5 | Emergency instruction (112) is present or added by the automatic notice | ☐ ✅ ☐ ⚠️ ☐ ❌ | |
| 2.6 | Medication changes are only described as "decide together with your doctor" — and the content is still complete (the phrase is not used to hide information) | ☐ ✅ ☐ ⚠️ ☐ ❌ ☐ N/A | |
| 2.7 | No promises of cure, no frightening or stigmatising wording | ☐ ✅ ☐ ⚠️ ☐ ❌ | |
| 2.8 | Consent/discharge modules state that they do not replace the personal conversation / the team's individual instructions | ☐ ✅ ☐ ⚠️ ☐ ❌ ☐ N/A | |
